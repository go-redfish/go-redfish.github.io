# go-redfish.github.io

The landing page of the [go-redfish](https://github.com/go-redfish) organisation: <https://go-redfish.github.io/>.

A Hugo site on the shared [landingkit](https://github.com/go-fleettools/landingkit) module. The
colours are read from `static/img/logo.svg` (`landingkit brand`), never chosen; the repositories on the
page are the `[[params.repos]]` of `hugo.toml`. Documentation: <https://go-redfish.github.io/docs/>.
